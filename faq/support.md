# Support requests

**How do I contact a human at 4PM?**
Use the **Support** page (the **Support** button in the user menu or footer) to file a request, or
click **"email a human"** in the Help chat. See [docs/12](../docs/12-getting-help.md#the-support-requests-page).

**What goes into a support request?**
A **category**, a **subject**, a **body** (Markdown) and an optional **attachment**. 4PM
auto-attaches context (the screen you were on, your org/project, app version, language) so you
don't have to describe your setup.

**Can I track my tickets?**
Yes — the Support page lists your requests with their **status**, filterable by status/category.
Open one to read the full **thread**, **reply** to support, or **close** it when resolved.

**How do I know when support replies?**
A new reply arrives as a **notification** (see [notifications](./quotas-and-notifications.md)).

**AI Help vs. human support — which do I use?**
Start with the in-app **Help** chat for instant answers about using 4PM; if it can't help
confidently it suggests escalating, and you can hand off to human support at any time (your
transcript comes along). See [docs/12](../docs/12-getting-help.md).

See also: [Get help & support](../docs/12-getting-help.md).
